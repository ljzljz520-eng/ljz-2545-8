# 古桥徒步导览网站（教学/验收演示）

一个纯前端（HTML + 原生 ES Module + CSS，无第三方运行时依赖）的古桥徒步网站。
**全部桥梁、地名、历史叙述与测绘数字均为虚构示例；网站不提供也不编造任何真实桥梁承载、吨级或车辆通行保证。**

## 快速开始

推荐用任意静态服务器打开（离线包会走真实分块文件）：

```bash
npm run build:packages     # 依据 js/data.js 生成 packages/v3 与 packages/archive-v1 的分块+清单
npm run serve              # = python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/index.html
```

也可直接 `file://` 打开：离线页会回退到内置同源块（哈希与文件一致），分块/缺块/哈希/激活门控语义完全相同。

运行验收（需要 Node ≥ 18）：

```bash
node tests/acceptance.mjs  # 31 项断言，覆盖全部关键验收点
```

## 页面

| 页面 | 文件 | 作用 |
| --- | --- | --- |
| 首页 | `index.html` / `js/home.js` | 意境图、桥梁卡、当日维护与延期、动态平面图 |
| 桥梁故事 | `bridge.html` / `js/bridge.js` | 结构、分端入口与穿越、桥窗观景、空间库通行段、维护区间、保护提示、拍摄方位验收 |
| 路线规划 | `planner.html` / `js/planner.js` | 半日/一日/亲子/无障碍；预制主题校验 vs 按图搜索；锁定点不可达解释与局部更新；验收场景开关 |
| 离线包 | `offline.html` / `js/offline.js` | 版本清单、分块下载与 sha256 校验、缺块/坏块注入、旧包回灌拒绝、只读快照 |

## 领域模型（`js/data.js`）

- `bridge`：桥梁本体（结构、桥窗、故事、保护、年度养护）。**没有 open 布尔字段。**
- `entrance`（kind=entrance 的节点）：桥头入口门，可被维护或临时指令单独关闭。
- `node`：停车场 / 入口 / 观景位 / 停留点 / 亭 / 桥面节点。
- `edge`：通行段，三种 kind：
  - `deck` 桥面段（如 b1 分南北两段，宽度分别记录）；
  - `approach` 桥头附近道路；
  - `cross` 跨片区连接。
  每段记录 `lenM / widthM / slopePct / surface / maintWindow`；`widthM`/`slopePct` 为 `null` 表示未测绘。
- `maintenance`：维护项目，作用到具体 `entrance` 或 `edge`，带计划区间与延期信息（m1 进行中、m2 延期、m3 已完工）。

## 关键规则实现（`js/graph.js`）

1. **一端维护 ≠ 整桥关闭**：边的可用性同时看（a）自身维护状态、（b）两端入口门控。
   m1 关闭南岸入口并封断南岸道路后，北岸入口与北端观景仍可达，穿越被切断。
2. **按硬约束搜索**：
   - 半日/一日：宽度下限 1.5m、坡度上限 15%；未知宽度/坡度可步行通过但**显式标注“无法确认分级”**。
   - 亲子：≥2.0m 且 ≤8%，且 `requireKnown`——宽度或坡度未知即硬阻断，文案为“无法确认适合儿童”。
   - 无障碍核对：≥3.0m 且 ≤4%，未知即“无法确认无障碍”。
   - 任何情况下都不自动给路线贴“适合儿童/无障碍”标签。
3. **不可达解释**：`diagnose()` 只报告“从起点可达前沿”上被阻断的边，避免列出全图无关阻断；
   每条阻断给出结构化原因（维护 id / 未知宽度 / 未知坡度 / 宽度超界 / 坡度超界 / 入口关闭）。
4. **锁定停留点 + 局部更新**：`planWithLocks()` 逐段求路；坏段标红、好段照给，
   并输出截断计划（保留锚点、待补回锁定点、终点是否仍可达），不重排整条路线、不编造绕行。
5. **拍摄方向**：以机位节点到桥体几何中心的真实方位角为准（北=0°，顺时针），与申报值比较，容差 ±35°。
   样例 p2（同一机位申报朝东北）被判“拍摄方向错误”。

## 离线包（`js/packages.js` + `packages/`）

- 清单 `manifest.json` 声明每块 `id/file/bytes/sha256`；逐块下载、逐块校验。
- **缺块或哈希不符 → `complete=false`，禁止激活**（“缺块不得当完整可用”）。
- 版本门控：低于 `minActivatable`、归档包（v1）一律拒绝激活、拒绝覆盖当前 v3。
- 激活后进入只读快照视图（localStorage 记录，吸顶横幅，可退出）。
- 离线页可勾选注入：慢速、`media1` 缺块(404)、`geo` 坏块(哈希不符)。

## 验收点对照（`node tests/acceptance.mjs`）

| 需求验收点 | 位置 / 操作 |
| --- | --- |
| 入口关闭、一端维护不影响另一端观景 | 默认场景 + 故事页“模拟临时关闭此入口”；验收【1】 |
| 路线跨区 + 维护时局部替代 | t2 双溪一日线、n-ramp 北岸连接 vs np-dp 林间径；验收【2】 |
| 宽度/坡度未知显示无法确认、不标亲子/无障碍 | np-dp（宽度未知）、g-vill（双未知）；规划页亲子 profile；验收【3】 |
| 锁定停留点不可达解释 + 局部更新 | 规划页“演示：锁定被维护切断的观景位”；验收【4】 |
| 维护延期 | m2（9-25→顺延 10-12）；一键场景；验收【5】 |
| 拍摄方向错误 | 故事页第七节 p1 合格 / p2 错误；验收【6】 |
| 旧包回灌拒绝、缺块不完整 | 离线页两组按钮；Node 包管理测试；验收【7】 |
| 原创视觉与设计说明 | 内联 SVG + `DESIGN.md` |
| 不编造真实承载保证 | 每页朱色声明，桥页“承载声明”卡，故事与数据标注虚构 |
